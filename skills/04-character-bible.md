# 04 · 角色一致性（Character Bible）

> 这是整个项目里**最难、也最决定成片质量**的一环。前面所有环节的瑕疵都是小瑕疵，
> 这一环崩了，成片直接不可看。

## 问题是什么

视频模型是**逐镜独立生成**的。同一个"林晚"，第 2 镜可能是短发圆脸，
第 7 镜就变成了长发尖脸 —— 因为模型没有任何机制知道这两个是同一人。

## 三层解法（按可靠性排序）

### 第 1 层：身份词块（identity_tokens）—— 必须做，但不够
把角色的外貌固化成一段**每次都逐字相同**的描述：

```
25岁女性，齐肩黑发，左眉尾有一颗小痣，鹅蛋脸，深灰色风衣，内搭白衬衫
```

规则：
- **逐字复用**。不许这次写"黑发"下次写"乌黑的头发"，模型会当成两个人。
- **只写稳定特征**。表情、动作、光线变化都别写进去。
- **锚点 2–4 个**。太多了模型顾不过来，太少了区分不开。
- **顺序固定**：年龄段 → 性别 → 发型 → 面部特征 → 固定服装。

### 第 2 层：定妆照 + 图生图 —— 一致性主力
1. 用 `T2IProvider` 给每个角色出一张**正面、中性光、纯色背景**的定妆照
   （`character_<名字>.png`）。
2. 生成该角色的关键帧时，把定妆照作为 `ref_image` 传进去（image-to-image）。
3. 生成视频时，用**已经带正确角色的关键帧**做首帧。

**这一层是骨架已经支持的**（`ImageProvider.png(..., ref_image=...)`）。
定妆照不配（`AI_DRAMA_T2I` 留空）时骨架会跳过第 1 步，
一致性会明显下降 —— 这是有意的权衡：不配也能跑，但你会看到差别。

### 第 3 层：关键帧复用 —— 同场次同角度的省力做法
如果两镜是同场景同角度，直接复用上一镜的关键帧当参考，不要重新抽。

## 服装与场景的例外

角色**换衣服换场景**是允许的，但要显式声明新的一套：

```json
{"name": "林晚", "identity_tokens": "25岁女性，齐肩黑发，左眉尾有一颗小痣，鹅蛋脸",
 "costumes": {
   "default": "深灰色风衣，内搭白衬衫",
   "home": "浅灰家居服，头发松松扎起"
 }}
```

外貌锚点（脸、发型、痣）**永远不变**，服装按场次切换。

## 输出契约

```json
{
  "characters": [
    {
      "name": "林晚",
      "identity_tokens": "25岁女性，齐肩黑发，左眉尾有一颗小痣，鹅蛋脸",
      "costumes": {"default": "深灰色风衣，内搭白衬衫"},
      "voice": "female_01",
      "portrait_prompt": "正面定妆照，纯灰背景，中性光，不笑，半身，{identity_tokens}，{costume}"
    }
  ]
}
```

`portrait_prompt` 是给 `T2IProvider` 的完整提示词，
可以在这里就拼好，骨架直接用。

## 自检清单

- [ ] 每个出现在画面里的角色都在 `characters` 里
- [ ] 每个角色的 `identity_tokens` 在整部片里**逐字一致**
- [ ] 锚点在 2–4 个之间，且都是**可见的静态特征**
- [ ] 换装的场次显式写了 `costumes`
- [ ] 音色不重复（两个角色别用同一个 `voice`）

## 提示词模板

```
你是角色设定师。为下列角色各写一份身份词块，用于跨镜头保持一致。

角色与处境：{roles}
视觉风格：{style}

要求：
- identity_tokens 顺序固定为：年龄段 → 性别 → 发型 → 面部特征 → 常服
- 只写稳定可见的静态特征，2–4 个锚点
- 不要写表情、光线、动作、情绪
- 额外产出一段 portrait_prompt：正面定妆照，纯色背景，中性光，半身

只输出 JSON，结构见 skills/04-character-bible.md 的「输出契约」。
```
