# 01 · 选题（Showrunner）

## 你要做的事

把一个模糊的一句话想法，变成一个**能在前三秒抓住人**的短剧选题。

## 竖屏短剧的硬约束

- **总时长 45–90 秒**，单集。不是网剧，是"一条"。
- **前三秒必须出事**：抛异常、抛悬念、抛冲突。不许铺环境、不许介绍人物。
- **只讲一个转折**。60 秒讲不了三幕，讲"一个反转"就够。
- **结尾留钩**：不闭环，让人想评论或看下一条。
- **台词密度高**：平均每 3–5 秒有一句人声，否则划走。

## 判断标准

写完之后逐条自问，任何一条不过就重写：

1. 这条片子的**一句话卖点**是什么？（说不出来 = 没选题）
2. 前三秒发生了什么**具体的事**？（"她很生气"不是事，"她把手机摔了"才是）
3. 观众会在第几秒产生"然后呢"？
4. 结尾那句话能不能单独发一条评论？
5. 这个题材**别人拍过吗**？拍过的话，我这里不一样在哪？

## 输出契约

```json
{
  "hook": "前三秒的具体事件（一句话）",
  "sell_point": "这条片子的一句话卖点",
  "twist": "唯一的那个转折",
  "closing_line": "结尾钩子台词",
  "casting": ["角色A（身份定语）", "角色B"],
  "title_candidates": ["标题1", "标题2", "标题3"],
  "risk": "这条片子可能失败的原因（诚实写）"
}
```

`title_candidates` 给 3 个：一个直白、一个悬念、一个情绪。发布时 A/B 测。

## 反例

| 错误 | 为什么错 | 改法 |
|---|---|---|
| "一个女孩的成长故事" | 没有事件，没有冲突 | "相亲当天，女孩发现对方的手机屏保是自己母亲" |
| "悬疑推理" | 是类型不是选题 | "外卖备注写着：别开门，我在你身后" |
| 前三秒是空镜+旁白 | 观众划走了 | 第一帧就是一个不该存在的东西 |
| 结尾讲道理 | 说教 = 完播率杀手 | 用一句台词把矛盾悬在那里 |

## 提示词模板

```
你是竖屏短剧的选题策划。目标平台：抖音 / 红果。单集时长 45–90 秒。

用户给的想法：{idea}
期望风格：{style}

请按以下要求产出一个选题，只输出 JSON：
- 前三秒必须是一个具体事件，不许铺陈
- 全片只允许一个转折
- 结尾必须留钩，不许闭环、不许说教

输出格式见 skills/01-showrunner.md 的「输出契约」。
```
