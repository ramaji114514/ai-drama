# 05 · 镜头提示词（Shot Prompt）

## 你要做的事

把一镜的 `action` + 角色身份词块 + 风格，拼成**图像提示词**、**视频提示词**和**两段负向提示词**。

骨架消费这四个字段：

| 字段 | 用途 | provider 方法 |
|---|---|---|
| `image_prompt` | 生成该镜关键帧 | `ImageProvider.png(prompt, ref_image=...)` |
| `last_frame` | 该镜结束那一刻（尾帧） | 同上，用作下一镜首帧 |
| `video_prompt` | 该镜的运镜/动作/时长 | `VideoProvider.submit({"prompt": ...})` |
| `negative_prompt` | 首帧/关键帧的负向词 | 独立的「负向提示词」输入框 |
| `video_negative` | 视频的负向词 | 同上，视频那条线 |

四段是**并列**的产物，不是"中间件"：用户拿到的是能直接粘进可灵/即梦/Sora/Veo 的文本。


## 拼装顺序（固定，不要改）

顺序按"模型最先看什么"排，不是按读起来顺不顺：

```
[主体与身份] + [动作] + [景别] + [焦段/景深/光比] + [人数] + [风格]
```

实例（短版，默认）：

```
角色 林溪：28岁女性，齐肩黑发，左眉尾有一颗小痣，深灰色风衣,
视线突然定住，瞳孔收缩, 特写，面部与情绪为主, 85mm，浅景深，柔光,
画面中只有 林溪, 冷调侧光，电影感青橙色调
```

风格放最后，因为它只是**气氛**：写在前面会和角色描述抢权重
（"冷青胶片感"压过"十七岁瘦削的少年"）。要长描述、长风格就用
`AI_DRAMA_PROMPT_DETAIL=full`。

## 硬性规则

1. **身份词块逐字复制**，不要改写、不要精简、不要换语序。
2. **不写厂商名、不写模型参数**。不要出现"8k/杰作/masterpiece"这类刷分咒语 ——
   它们对现代模型基本无效，只会稀释真正的信息。
3. **负面描述一律进负向词，不进正向**。要"空房间"，不要写"没有人" ——
   正向提示词里每个名词都会被当成"要画的东西"，模型只认名词、不太认否定。
   所以 `no watermark` 经常换回来一个水印。正向与负向必须分开两个字段。
4. **视频提示词只描述"动"**。画面内容已经在首帧里了，
   视频提示词写"镜头缓慢推进，人物转头看向门口"就够，
   重复描述长相是浪费 token 还容易让模型改脸。
5. **视频提示词必须交代时长**。写成"……，15 秒内匀速完成，不加速也不放慢"。
   不写，模型会在长镜头里前两秒演完、剩下十几秒人物杵着不动；
   短镜头则会在最后一秒硬刹车。
6. **景别只说一次**。`action` 开头已经写了"俯拍特写"就不要在骨架里再补一句
   "特写，面部与情绪为主" —— 两句都留，模型会试着把两个景别都装进画面
   （实测是画中画）。
7. **运镜写在最前面**。可灵会把末尾那句运镜当成"可选的补充"，放后面经常被
   忽略，画面自己横过去。正确顺序是"怎么拍 → 谁做了什么 → 到哪儿收"。
8. **人数写死**。只写"林溪站在门口"，模型会在空处补人。写"画面中只有 林溪"，
   空镜写"画面中没有人"。
9. **有台词就让人开口**。补一句"人物开口说话，口型与台词同步"，
   否则画面里的人闭嘴站着，配音成了画外音。
10. **长度控制**：画面描述（不含参考锁定段）短版默认 220 字以内，
    视频提示词 30–60 字。超过 200 字模型开始"顾此失彼"。
11. **拼完自检**。`ai_drama/core/lint.py` 会在 stage02 末尾体检：没写
    `end_action`、运镜做不完、有台词没开口、一镜多个运镜、没有负向词。

## 负向词怎么分组

分三类，不要混在一起：

| 组 | 词 | 什么时候写 |
|---|---|---|
| 解剖 | 畸形手指、多余手指、五官错位、皮肤塑料感 | **画面里有人才写**。空镜写这些只会把模型往人上引 |
| 版面 | 文字、字幕、水印、logo、边框、分屏 | 永远写。出现一次这张就废了，只能重出 |
| 画质 | 低分辨率、模糊、过曝、噪点、色块 | 永远写 |
| 时间 | 人物变脸、五官漂移、画面闪烁、跳帧、动作僵住不动 | **只给视频那条线**。静态图里这些词毫无意义 |

`video_negative` = 时间 + 版面。`negative_prompt` = 解剖（有人时）+ 版面 + 画质。


## 竖屏构图

- 全部 **9:16**。骨架默认 `(720, 1280)`。
- 主体**居中偏上**，下方留字幕安全区（约 15% 高度）。
- 别写"横向构图""大远景" —— 竖屏里横向信息会丢。

## 输出契约

```json
{
  "order": 2,
  "image_prompt": "close, 25岁女性，齐肩黑发...",
  "last_frame": "close, 25岁女性，齐肩黑发..., 她把伞收起来，水顺着伞骨滴下",
  "video_prompt": "镜头缓慢推进，人物转头看向门口，霓虹光轻微闪烁，15 秒内匀速完成，不加速也不放慢",
  "negative_prompt": "畸形手指、多余手指、五官错位、文字、字幕、水印、低分辨率、模糊",
  "video_negative": "人物变脸、五官漂移、画面闪烁、跳帧、动作僵住不动、文字、字幕、水印"
}
```

## 常见错误

| 错误 | 后果 |
|---|---|
| 身份词块改了标点或语序 | 模型当成另一个角色，一致性崩 |
| 视频提示词里重写长相 | 模型按文字重新"造脸"，和首帧不像 |
| 图像提示词塞 300 字 | 关键信息被稀释，出图随机 |
| 写"masterpiece, best quality, 8k" | 无效噪声 |
| 正面写"不要有水印" | 正向里的名词被当成要画的东西，反而出个水印 |
| 空镜也写"畸形手指" | 把模型往人上引，空房间长出一个人 |
| 提示词里有中英混排的品牌名 | 触发内容审核或风格漂移 |

## 平台方言

同一镜要能粘进不同平台，但**骨架只写一套**：`ai_drama/core/dialects.py` 负责翻成
各家写法。你不需要在这里写"可灵版/即梦版"，只要保证：

- 首帧、尾帧、运镜、负向词**各写各的**（别揉成一段）；
- 负向词只写"不要什么"，绝不重复进正向；
- 运镜里带时长交代（"15 秒内匀速完成"），因为方言层会按平台决定留不留它。

方言层知道的能力矩阵（都查过官方文档）：

| 平台 | 负向框 | 尾帧图 | 上限 | 运镜写法 |
| --- | --- | --- | --- | --- |
| 通用 | 有 | 支持 | 4000 | 自然语言 |
| 可灵 | 有 | 支持 | 2500 | 运镜放最前 |
| 即梦 | 无 | 支持 | 2000 | 自然语言 |
| Seedance | 无 | 支持 | 2000 | 素材写 `@图片1` |
| 海螺 | 无 | 支持 | 2000 | 方括号指令 `[Push in]` |
| Runway | 无 | 支持 | 2000 | 英文更稳 |
| Veo | 有（500 字） | 支持 | 2000 | 英文更稳 |
| Sora | 无 | 只认首帧 | 2000 | 长句更好 |

这些差异集中在那一个文件里，新增平台只改那里。

## 提示词模板

```
你是镜头提示词工程师。为下列镜头写图像提示词和视频提示词。

镜头：{shot_json}
角色身份词块（必须逐字复用）：{identity_tokens}
视觉风格：{style}

要求：
- 图像提示词拼装顺序：景别 + 主体与身份 + 动作 + 环境 + 机位与运动 + 光线与风格
- 视频提示词只描述运动与变化，30–60 字，不要重复长相，并写明"多少秒内匀速完成"
- 负向词分两段：图片的（解剖+版面+画质）和视频的（时间+版面），不要合并
- 空镜不写解剖类负向词
- 竖屏 9:16，主体居中偏上，下方留字幕区
- 不要出现厂商名、模型名、画质刷分咒语

只输出 JSON，结构见 skills/05-shot-prompt.md 的「输出契约」。
```
