# 02 · 剧本（Screenwriter）

## 你要做的事

把选题落成**分场分镜表**，这是整条流水线最重要的一份 JSON。
骨架的后面五个阶段全部消费它。

## 结构规则

- **场次数 2–5 场**。默认 3 场：`引子 → 推进 → 爆发`。
- **每场 3–6 镜**。默认 4 镜。
- **一镜一动作**。一个镜头里只发生一件事。想写两件事 = 写两镜。
- **总镜头数控制在 8–20 镜**。20 镜以上成本会失控，而且节奏会碎。

## 台词规则

- 台词写在 `dialogue` 字段，格式固定为 `角色名：台词内容`。
  骨架靠这个冒号切角色、分配音色。**中文全角冒号 `：` 或半角 `:` 都认，但必须有一个。**
- 没有台词就留空串 `""`，不要写 `null`。
- 一句台词**不超过 30 字**。超了就拆成两镜。
- 台词要能单独截出来当字幕，别写"（沉默）"这种没有声音的东西。

## 时长规则（最容易出错的地方）

`duration_sec` 决定音画能不能对齐，必须给具体数字：

| 内容类型 | 建议时长 |
|---|---|
| 空镜 / 环境建立 | 1.5 – 2.5s |
| 无台词动作镜 | 2.0 – 3.5s |
| 有台词镜 | 按台词字数 ÷ 5 字/秒 + 1s 余量，一般 3 – 5s |
| 特写情绪镜 | 1.5 – 2.5s |

**自检**：把所有 `duration_sec` 加起来，落在 45–90 秒之间。
不到 45 秒就加镜，超过 90 秒就删镜 —— 不要靠改单价蒙过去。

## 输出契约

```json
{
  "title": "片名（12 字以内）",
  "logline": "一句话梗概",
  "style": "视觉风格描述（色调/光线/质感）",
  "characters": [
    {"name": "林晚", "identity_tokens": "25岁女性，短发，左眉有痣，深灰风衣",
     "voice": "female_01", "description": "在这个故事里的处境"}
  ],
  "scenes": [
    {
      "scene_id": "sc01",
      "title": "引子：异常出现",
      "summary": "这一场发生什么（一句话）",
      "location": "老城区出租屋",
      "time_of_day": "深夜",
      "shots": [
        {"order": 0, "framing": "establishing", "action": "画面描述",
         "dialogue": "", "location": "老城区出租屋", "duration_sec": 2.0}
      ]
    }
  ]
}
```

字段说明：
- `identity_tokens` 是**给图像模型的角色身份词块**，见 `04-character-bible.md`。
  它必须包含**外貌锚点**（发型、面部特征、固定服装），因为跨镜头一致性全靠它。
- `voice` 从骨架支持的音色里选（默认 `female_01` / `male_01`）。
- 同一场里所有镜头默认继承场次的 `location`，要换景就在**镜头级**覆盖。

## 反例

| 错误 | 为什么错 |
|---|---|
| 一镜写"她走进来，环顾四周，然后坐下" | 一件事里三个动作，视频模型会糊 |
| `"dialogue": "（沉默）"` | 没有可合成的声音 |
| 台词 60 字 | 配出来 12 秒，视频只有 4 秒，音画必炸 |
| 不给 `duration_sec` | 骨架会按默认 3 秒算，累计时长全错 |
| 角色只在台词里出现，没进 `characters` | 拿不到音色，也拿不到参考图 |

## 提示词模板

```
你是竖屏短剧编剧。写一部单集短剧的分镜剧本。

想法：{idea}
风格：{style}
场数：{scene_count}
每场镜头数：{shots_per_scene}

硬性要求：
- 前三秒就是具体事件，不铺陈
- 每镜只发生一个动作
- 台词格式严格为「角色名：内容」，不超过 30 字，无台词留空串
- 每镜必须给 duration_sec，全片总时长落在 45–90 秒
- 角色的 identity_tokens 必须含外貌锚点，供图像模型做跨镜头一致性

只输出 JSON，结构见 skills/02-screenwriter.md 的「输出契约」。
不要输出任何厂商参数（分辨率、帧数、模型名）。
```
